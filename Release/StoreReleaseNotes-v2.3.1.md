Hyper Battery Monitor v2.3.1 introduces the new application name, adds support for 11 languages with automatic Windows-language detection, improves DPI-aware Settings layouts and Dynamic Icon Colors, reorganizes application assets, and includes multiple localization and visual fixes. Desktop upgrades now migrate existing settings and battery history to the new Hyper Battery Monitor data folder, improve protection against updates while the application is still running, and clean up Start with Windows entries during uninstall.
