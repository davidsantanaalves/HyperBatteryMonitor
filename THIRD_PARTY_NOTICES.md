# Third-Party Notices

## Historical development reference

Earlier versions of Hyper Battery Monitor consulted the open-source
HyperX-Cloud-2-Battery-Monitor project by auto94, distributed under the MIT License.
Historical HID interface-selection logic was adapted from that reference and
subsequently replaced. This historical use has not been erased from Git.

The current HyperX device protocol implementation is based primarily on
independent analysis of HyperX NGENUITY and the protocol research documented
by this project. The v2.3.1 audit identified no relevant copied or adapted
implementation from the referenced project remaining in the current source.
This is a technical provenance assessment, not a definitive legal determination.

Original repository: https://github.com/auto94/HyperX-Cloud-2-Battery-Monitor

The original notice is retained conservatively for historical development use.
It does not assert that the current implementation contains that project's code.
See [the provenance audit](https://github.com/davidsantanaalves/HyperBatteryMonitor/blob/v2.3.1/ProvenanceAudit-auto94-v2.3.1.md) for evidence and limits.
