# Security Policy

## Supported Versions

Hyper Battery Monitor is a Windows desktop application for monitoring battery information and supported status indicators of compatible HyperX wireless headsets.

Security maintenance is focused on the latest stable release.

| Version | Security Support |
|---|---|
| Latest stable release (currently v2.4.0) | Supported |
| Older stable releases | Not actively maintained |
| Beta and pre-release versions | Testing only; no guaranteed security maintenance |

Users are encouraged to install the latest stable release from the official GitHub Releases page.

## Reporting a Vulnerability

If you discover a potential security vulnerability in Hyper Battery Monitor, please report it privately through GitHub's **Private Vulnerability Reporting** feature:

[Report a vulnerability through GitHub Security Advisories](https://github.com/davidsantanaalves/HyperBatteryMonitor/security/advisories)

Please do not disclose security vulnerabilities in public GitHub Issues, Pull Requests, or Discussions before they have been assessed.

### What to Include

When submitting a report, please provide:

- A clear description of the vulnerability and its potential impact.
- The affected application version and Windows version.
- Steps to reproduce the issue, when available.
- Relevant logs, screenshots, or proof-of-concept details.
- Any suggested mitigation or remediation.

Please avoid including passwords, access tokens, personal information, or other sensitive data unless strictly necessary.

## Vulnerability Handling

Reports will be reviewed and assessed according to their severity, reproducibility, and potential security impact.

Confirmed vulnerabilities may be addressed through a security fix, a new application release, or documented mitigation guidance.

Response and resolution times may vary depending on the complexity and severity of the issue. No fixed response or remediation timeline is guaranteed.

We encourage coordinated disclosure so users have a reasonable opportunity to apply available fixes before technical details are publicly released.

## Scope

This policy covers security vulnerabilities in the Hyper Battery Monitor application's source code, build and distribution processes, and official release artifacts.

Vulnerabilities in third-party software, headset firmware, device drivers, or vendor services should generally be reported to their respective maintainers.

Hyper Battery Monitor is an independent open-source project and is not affiliated with or endorsed by HyperX or HP.
